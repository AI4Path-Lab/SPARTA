# SPARTA
Spatial Pathology Analysis of Relationships and Tissue Architecture (SPARTA) is a set of  image processing algorithm for histology that can quantify the spatial interactions between cells and model intercellular interactions.

*Instructions* 

Intracell.py: You must have a root directory, with at least two directories within that root directory. The script currently uses tiff and png files.
Sparta.py : Root directory must be set, but all files must be within the root directory. to specify between the two groups, you should name each file such that the first letter should be "C" or D". All image file types are accepted.
